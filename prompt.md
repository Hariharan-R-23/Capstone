### CODE SETUP REQUIREMENTS

Please generate a modular, production-ready Python repository with the following 4 files:

#### 1. `dataset_loader.py`
- Load the HuggingFace dataset (`manoh2f2/tsterbak-lyrics-dataset-with-emotions`).
- Preprocess and map metadata fields into special system prompts for Supervised Fine-Tuning (SFT).
- Required Prompt Structure:
  `[Artist]: {artist} | [Mood]: {emotion} | [Genre]: {genre} | [Theme]: {theme}`
- Implement a clear placeholder class `TamilLyricDatasetLoader` alongside `EnglishLyricDatasetLoader` to allow seamless dataset swapping in Phase 2.

#### 2. `sft_trainer.py`
- Implement Parameter-Efficient Fine-Tuning (LoRA / QLoRA) using `peft` and `transformers.SFTTrainer`.
- Base Model: `meta-llama/Meta-Llama-3-8B-Instruct` (or `Mistral-7B-v0.1` as default configurable parameter).
- Integrate metadata tokens (`[Artist]`, `[Mood]`, `[Genre]`, `[Theme]`) into model tokenization.
- Save LoRA adapters upon completion.

#### 3. `reward_engine.py`
- Implement a Multi-Objective Reward Function for steering the RL engine:
  1. Phonetic Rhyme Reward: Evaluates end-of-line rhyme density using `pronouncing` (CMUdict) for English. Include an abstracted base class interface `BaseRhymeEvaluator` so a Tamil phonetic analyzer can be injected in Phase 2.

  3. Combined Reward Function: Outputs a weighted scalar score combining both components for TRL optimization.

#### 4. `rl_ppo_trainer.py`
- Load the LoRA-fine-tuned base model from Step 2.
- Integrate `trl.PPOTrainer` to optimize the policy network against the composite scalar score generated by `reward_engine.py`.
- Implement logging via `Weights & Biases` (W&B) or simple tensorboard metrics (tracking policy loss, KL divergence, reward convergence).
